# Twilight Sword Character Sheet

A simple character sheet extension for Owlbear Rodeo

**Your character data is stored in your browser's local storage so be sure to export it often so
that nothing is lost if your browser data is wiped. The export button is in the left drawer menu.**

![Screenshot showing the data export button](https://nboughton.uk/apps/obr-twilight-sword-sheet/image-4.png)

## Features

- Track encumberence, equipped items/weapons, health and stamina, expended spells/feats etc

- Handle short/long rest rolls

- Status conditions managed in their own tab

- Durability enabled optionally in the left drawer

## Getting Started

- Set your Ability scores by clicking the number next to the Ability name
- Set your Max hearts by clicking the heart icon and Max stamina by clicking the blue diamond icon
- Armour is set automatically from your equipped inventory

![Screenshot showing abilities, hearts, armour and stamina](https://nboughton.uk/apps/obr-twilight-sword-sheet/image-1.png)

- Click the Edit toggle on the right to enable edit mode in ABILITIES and INVENTORY tabs then use
  the + button to add Feats, Spells, Items, Weapons or Armour

![Screenshot showing the Edit toggle and an editable view of a Feat](https://nboughton.uk/apps/obr-twilight-sword-sheet/image-2.png)

- On the inventory tab you can set an item to equipped by toggling the E icon in the top right
  corner of the edit box. Equipped items are not counted towards your backpack capacity.
- Heavy weapons are automatically counted as 2 equipped items, and equipping two Small weapons
  automatically counts as a single equipped item

![Screenshot showing the inventory tab in edit mode](https://nboughton.uk/apps/obr-twilight-sword-sheet/image-3.png)

On the STATUS EFFECTS tab you can toggle any of the games status effects, effects the impose
disadvantage on abilities will mark those abilities red while active.

![Screenshot displaying the STATUS EFFECTS tab](https://nboughton.uk/apps/obr-twilight-sword-sheet/image-5.png)
